# Typography

`Neo Sans Pro` is the primary company typeface. The UI package exposes it as `--font-sans` and maps it to Tailwind `font-sans`.
Until licensed Neo Sans Pro web files are available, the package loads Poppins as the interim fallback.

```css
:root {
  --font-sans: "Neo Sans Pro", "Poppins", Arial, sans-serif;
}
```

Licensed web font files should be self-hosted from `packages/ui/public/fonts` when available. Until then, the CSS variable falls back to Arial and the system sans-serif stack.
