# Typography

The official Milaha Brand Guidelines specify Arial for English documents and Arial Arabic for Arabic content.
The UI package exposes this policy as `--font-sans` and maps it to Tailwind `font-sans`.

```css
:root {
  --font-sans: Arial, "Arial Arabic", sans-serif;
}
```

Do not import substitute web fonts for Milaha UI foundations. Use the shared stack so product screens, internal documents, and bilingual surfaces remain aligned.
