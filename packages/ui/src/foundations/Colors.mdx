# Colors

The palette starts with the supplied company swatches, then maps them into semantic roles for product UI.
App code should prefer semantic tokens such as `primary`, `accent`, `text`, `background`, and `border`.

## Semantic Roles

| Role | Value | Usage |
| --- | --- | --- |
| `primary` | `{semanticTokens.color.primary.value}` | Main actions and selected states |
| `accent` | `{semanticTokens.color.accent.value}` | Accent actions, focus, and active indicators |
| `text` | `{semanticTokens.color.text.value}` | Default readable text |
| `info` | `{semanticTokens.color.info.value}` | Informational states |
| `background` | `{semanticTokens.color.background.value}` | Default surface |
| `backgroundSoft` | `{semanticTokens.color.backgroundSoft.value}` | Soft sections and empty states |
| `border` | `{semanticTokens.color.border.value}` | Dividers, inputs, and card borders |

## Contrast Notes

- Use white text on purple and navy.
- Use navy text on orange, teal, mint, and white.
- Do not place white body text on orange or teal; those combinations are not strong enough for normal text.
- Use orange for focus rings because it remains visible against white and mint surfaces.
